---
name: استعادة إعدادات Replit
description: سلوك استبدال ملف .replit عند استخدام أداة التحقق والاستعادة
---

عند استعادة `.replit` عبر أداة التحقق، يجب أن يحتوي الملف المؤقت على النسخة الكاملة من الإعدادات الحالية، وليس فقط أسطر modules وrun وhidden.

**Why:** الاستبدال يتم على مستوى الملف بالكامل؛ تمرير نسخة مختصرة حذف إعدادات النشر والمنافذ وworkflow الرئيسي، وأدى إلى إزالة workflow التطبيق تلقائيًا.

**How to apply:** اقرأ النسخة الحالية أو نسخة Git كاملة، أنشئ ملفًا مؤقتًا مطابقًا لها، ثم مرّره لأداة التحقق قبل استبدال `.replit`.
